# Lexer outputs

The lexer shall recognize:

```
CALL
IDENTIFIER
TYPE
STRING
INTEGER
FLOAT
BOOLEAN
COLON
LESS_THAN
GREATER_THAN
NEWLINE
END_CODE

```

| Token | Meaning |
| --- | --- |
| `CALL` | call function |
| `IDENTIFIER` | variable name or function or symbol |
| `TYPE` | type name like `int`, `string`, `float` |
| `STRING` | strting value like `"Hello"` |
| `INTEGER` | integer like `123` |
| `FLOAT` | float number like `3.14` |
| `BOOLEAN` | boolean vaue like `true` or `false` |
| `COLON` | symbol `:` |
| `LESS_THAN` | symbol `<` |
| `GREATER_THAN` | symbol `>` |
| `STATEMENT_END` | after evry ended operation |
| `END_CODE` | The end of all code |

---

# Lang rules

**1-Call function**:

Example:

```json
CALL print value<str>:"Hellow World"
```

- `CALL` : Used to call function
- `print` : Function name
- `value` : Method name
- `<str>` : Type name
- `:` : used to set method
- `“Hellow World”` : The string value

---

# Supported types

- `str` : the standard string → `std::string`
- `int` : the standard intiget → `int`
- `int32` : the standard intiget → `int32_t`
- `int64` : the intiger of 64 bit → `int64_t`
- `float` : the standard double → `double`
- `bool` : the standard boolean → `bool`
