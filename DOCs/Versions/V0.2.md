# ValtCommand v0.2

## Overview

Version 0.2 focuses on transforming ValtCommand from a basic parser into a fully analyzable and executable language.

This release introduces semantic analysis, runtime execution, scopes, nested function calls, and significantly improved diagnostics.

---

## Added

### Runtime Engine

Added the runtime system responsible for executing parsed AST nodes.

Features:

- Function execution
- Nested function calls
- Value propagation
- Runtime scopes

---

### Scope System

Introduced hierarchical scopes.

Features:

- Function lookup
- Variable lookup
- Parent scope traversal
- Block scope support

---

### Semantic Analysis

Added a semantic analysis stage before execution.

Checks include:

- Function existence
- Argument validation
- Required arguments
- Argument type compatibility
- Return type validation

---

### Recursive Parser

The parser can now parse nested function calls.

Example:

```txt
CALL print
    value<void>:
        CALL Pi
            v<str>:"boy"
        END
END
```

---

### Type Validation

Improved type checking.

Supported validations:

- Argument type validation
- Return type propagation
- Compatibility checking

---

### Error Handling

Improved diagnostics and reporting.

New error categories:

- SyntaxError
- NameError
- TypeError
- ArgumentError

Examples:

```txt
NameError:
Function 'printt' is not defined.

ArgumentError:
Function 'Pi': Missing required argument 'v'.

TypeError:
Expected 'float', but got 'str'.
```

---

### Lexer Improvements

Added support for additional language tokens.

New tokens:

- LEFT_BRACKET
- RIGHT_BRACKET
- LEFT_BRACE
- RIGHT_BRACE
- LEFT_PAREN
- RIGHT_PAREN
- PLUS
- MINUS
- STAR
- SLASH
- EQUAL
- CARET

---

## Internal Improvements

- Cleaner parser implementation
- Better AST traversal
- Improved function registry
- Improved runtime architecture
- Better separation between parsing, semantic analysis, and execution
