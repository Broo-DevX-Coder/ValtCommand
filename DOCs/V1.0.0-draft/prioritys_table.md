## Mathimatical operations prioritys table:

| Priority | Operators              | Meaning                                            | Associativity                   |
| -------- | ---------------------- | -------------------------------------------------- | ------------------------------- |
| 1        | `()`                   | Parentheses / grouping                             | Inner expression first          |
| 2        | `func(...)`            | Function calls                                     | Left to right for chained calls |
| 3        | `+x`, `-x`, `NOT x`    | Unary plus, unary minus, logical NOT               | Right to left                   |
| 4        | `*`, `/`, `div`, `mod` | Multiplication, division, integer division, modulo | Left to right                   |
| 5        | `+`, `-`               | Addition, subtraction                              | Left to right                   |
| 6        | `<`, `>`, `<=`, `>=`   | Relational comparisons                             | Non-associative                 |
| 7        | `==`, `!=`             | Equality comparisons                               | Non-associative                 |
| 8        | `AND`                  | Logical AND                                        | Left to right                   |
| 9        | `OR`                   | Logical OR                                         | Left to right                   |
